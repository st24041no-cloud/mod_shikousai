# FesFlow レジ確認アシスタント

FesFlowの既定モッドAPIだけを使用し、レジ画面に次の機能を追加します。

- 売り切れ商品と残数5以下の商品の在庫警告
- カート内商品の名前・説明文から抽出したアレルギー候補と注意事項
- 復唱、数量、注意事項、支払い、引渡しの会計前チェックリスト
- 同一レジ画面で会計を10件検出するごとの「ingredient1を解凍してください」通知

「レジ確認」ボタンを押すと全画面の確認画面を表示します。通信状態を表示していた旧機能は削除しました。

## 導入URL

```text
https://st24041no-cloud.github.io/mod_shikousai/manifest.json
```

FesFlowの「URLからモッドを導入」へ上記URLを入力し、モッドを有効化して「拡張設定を保存」してください。旧版を導入済みの場合は、旧版をアンインストールしてから新版を導入します。

## アレルギー表示に関する注意

アレルギー候補はメニュー名・説明文からの単純なキーワード抽出です。安全性を保証するものではありません。正確な原材料情報をメニュー説明へ登録し、会計時には必ず原材料表示および調理担当者へ確認してください。

## FesFlow側の制約

モッドから注文確定、在庫更新、外部通信、データベース保存はできません。チェック状態はその会計画面内だけで保持され、ページの再読み込みではリセットされます。

FesFlowのモッドSDKは累計注文数を提供しないため、解凍通知では「商品が入ったカートが空になった回数」を会計件数として数えます。ページを再読み込みすると0件へ戻り、手動のカート全消去も1件として数えられます。
